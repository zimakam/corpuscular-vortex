## What is this

CorpuscularVortex unifies three physics objects into one:

- Vortex core (circulation Γ, core radius, axis)
- Corpuscle (charge = Γ, spin = ±1, mass = |Γ|)
- Field (magnetic via Ampère + gravitational via external)

In literature, vortex, particle, and field are separate objects. **Here — one object.**

## Uniqueness

### 1. Three in one
Vortex core + particle attributes + fields.

### 2. Charge = circulation
Charge is not a separate quantity — it equals Γ.

### 3. Link network
Four link types: STRONG, WEAK, EM, GRAV.
